⚡ GridRunner — Setup Guide

🎉 Free 7-Day Trial — no license key needed. Just leave LICENSE_KEY blank. After 7 days, buy a license at gridrunner.tools.

What You Need

1. A Solana wallet with USDC (Phantom or Solflare)
2. A free Render.com account
3. A free Alchemy.com account (for Solana RPC)
⚠️ Render requires a credit card even for free tier. They place a $1 verification hold that is refunded immediately. You will NOT be charged.

Step 1 — Get an Alchemy API Key

Alchemy provides the RPC (Remote Procedure Call) connection your bot uses to read the Solana blockchain — prices, balances, and transactions. Without it, the bot can't see anything on-chain.

1. Go to alchemy.com → sign up (free)
2. Click Create App → choose Solana → Mainnet
3. Click API Key → copy the long string

Step 2 — Deploy to Render

🚀 Deploy to Render

On the Render page:
• Name: any name you want
• Branch: release
• Plan: Free

Required — fill these 4 in:
VariableWhat to enterWhere to find it
SOL_PRIVATE_KEY Your wallet's private key Phantom → Settings → Export Private Key
This lets the bot sign transactions. Never share this with anyone.
SOL_WALLET_ADDRESS Your wallet's public address Phantom — tap the address at the top to copy
ALCHEMY_KEY The API key from Step 1 Alchemy dashboard → API Key
LICENSE_KEY Leave blank for free 7-day trial Already have a license? Paste it here.
Buy one at gridrunner.tools. No key needed to start — trial is automatic.
Optional — these add features but work fine if left blank:
VariableWhat it doesWhere to get it
API_SECRET Password-protects your dashboard Make up any password you want
Without this, anyone with your URL can access the dashboard.
TG_BOT_TOKEN Telegram alerts when bot buys/sells Talk to @BotFather on Telegram → create a bot → copy the token
Looks like: 123456:ABC-DEF1234ghikl...
TG_CHAT_ID Which Telegram chat gets alerts Add @userinfobot to a Telegram group or DM it → copy the ID number
Must fill in TG_BOT_TOKEN above first.
Click "Create Web Service" → deploys in ~2 minutes.
Your bot URL will be https://your-name.onrender.com

Step 3 — Start Trading

1. Open your bot URL → dashboard appears
2. Select Grid strategy + BTC/USDC (or any pair)
3. Start in Paper mode to test safely
4. Click Start → grid begins running
5. When ready, tap Paper: ON to switch to LIVE

⏰ Keep It Running 24/7

Render's free plan puts the bot to sleep after 15 minutes of no visitors.

1. Sign up at UptimeRobot.com (free)
2. Add New Monitor → type HTTP(s)
3. URL: your bot's Render URL
4. Interval: 5 minutes

This pings your bot every 5 minutes so it never sleeps.

After 7 Days

When your trial ends, the bot stays running but switches to paper-only mode. To continue live trading:

1. Buy a license at gridrunner.tools
2. Go to Render → your service → Environment
3. Paste the license key into LICENSE_KEY
4. Click Save and redeploy

Troubleshooting

• Swaps failing? You need ~$5 USDC minimum + 0.01 SOL for gas fees
• Dashboard not loading? Wait 30-60 seconds, Render is still booting
• Stuck in paper mode? Tap the Paper button in the top-right of the dashboard
• No prices showing? Make sure ALCHEMY_KEY is correct
• Other issues? On Render → Logs tab shows error messages
